# FMSMP — وب‌سایت رسمی

وب‌سایت سرور ماینکرفت فارسی **FMSMP**؛ سرور اسلایم‌فان و اقتصادی با چت صوتی زنده.

🎮 **آی‌پی سرور:** `fmsmp.9craft.vip` · Java Edition 1.21.x

---

## امکانات سایت

- **صفحه اصلی سینمایی** — هیرو با پس‌زمینه اختصاصی، کپی سریع آی‌پی، نوار آمار متحرک
- **معرفی سرور** — شش کارت ویژگی با افکت اسپات‌لایت، متریک‌های شمارشی
- **راهنمای اتصال** — چهار مرحله ساده برای ورود به سرور
- **فروشگاه** — چهار رنک سلطنتی و سه بسته شارد با خرید از طریق دیسکورد
- **قوانین سرور** — چهار دسته‌بندی کامل
- **سوالات پرتکرار** — آکاردئون هشت‌تایی
- **حساب کاربری** — ثبت‌نام/ورود، مشاهده موجودی شارد و تاریخچه تراکنش
- **پنل مدیریت** — آمار، مدیریت کاربران، افزودن شارد، لاگ فعالیت‌ها
- **حالت روشن و تاریک** · ریسپانسیو کامل · RTL · دسترس‌پذیر

> ⚠️ داده‌های کاربران در `localStorage` مرورگر ذخیره می‌شود (نسخه بدون بک‌اند).

---

## اجرا در محیط توسعه

```bash
npm install
npm run dev        # http://localhost:5173
```

## ساخت خروجی نهایی

```bash
npm run deploy     # بیلد می‌کند و index.html ریشه را بروزرسانی می‌کند
```

خروجی یک فایل `index.html` **تک‌تکه** است (CSS، JS و تصویر همه inline)، پس روی
GitHub Pages یا هر هاست استاتیک ساده بدون تنظیمات اضافه کار می‌کند.

```bash
npm test           # تست دود: رندر همه صفحات
npm run preview    # پیش‌نمایش خروجی بیلد
```

## ساختار پروژه

```
src/
├── index.html          قالب HTML و متاتگ‌های SEO
├── main.jsx            نقطه ورود
├── App.jsx             مسیریابی، تم، توست، نوار پیشرفت
├── data/site.js        ⭐ پیکربندی مرکزی: قیمت‌ها، متن‌ها، لینک‌ها
├── lib/store.js        ذخیره‌سازی، فرمت اعداد فارسی، کپی، لاگ
├── components/         Navbar · Footer · Icon · Gate · ui
├── pages/              Home · Auth · Profile · Owner
├── styles/             base · layout · sections · app
└── assets/hero.jpg     پس‌زمینه هیرو

scripts/
├── smoke-test.mjs      تست رندر صفحات
└── build-pages.mjs     کپی خروجی به ریشه
```

## ویرایش محتوا

بیشتر تغییرات رایج فقط در **یک فایل** انجام می‌شود: `src/data/site.js`

| می‌خواهید چه چیزی را عوض کنید؟ | کجا |
| --- | --- |
| آی‌پی سرور، نسخه، لینک دیسکورد | `SITE` |
| قیمت و امکانات رنک‌ها | `RANKS` |
| بسته‌های شارد | `SHARDS` |
| کارت‌های ویژگی | `FEATURES` |
| مراحل اتصال | `STEPS` |
| قوانین | `RULES` |
| سوالات پرتکرار | `FAQ` |

پس از ویرایش، `npm run deploy` را اجرا کنید تا `index.html` ریشه بروز شود.
