# FMSMP — وب‌سایت رسمی

وب‌سایت سرور ماینکرفت فارسی **FMSMP**؛ سرور اسلایم‌فان و اقتصادی با چت صوتی زنده.

🎮 **آی‌پی سرور:** `fmsmp.9craft.vip` · Java Edition 1.21.x
🌐 **آدرس سایت:** <https://fmsmp.github.io/FMSMP/>
💬 دیسکورد: <https://discord.gg/gTqTv9FqFx>
---

## امکانات سایت

- **صفحه اصلی سینمایی** — هیرو با پس‌زمینه اختصاصی، کپی سریع آی‌پی، نوار آمار متحرک
- **معرفی سرور** — شش کارت ویژگی با افکت اسپات‌لایت، متریک‌های شمارشی
- **راهنمای اتصال** — چهار مرحله ساده برای ورود به سرور
- **فروشگاه** — چهار رنک سلطنتی و سه بسته شارد با خرید از طریق دیسکورد
- **قوانین سرور** — چهار دسته‌بندی کامل
- **سوالات پرتکرار** — آکاردئون هشت‌تایی
- **حساب کاربری** — ثبت‌نام/ورود، مشاهده موجودی شارد و تاریخچه تراکنش
- **پنل مدیریت** — آمار، مدیریت کاربران، افزودن شارد، لاگ فعالیت‌ها
- **وضعیت زنده سرور** — تعداد بازیکنان آنلاین مستقیماً از API عمومی ماینکرفت
- **حالت روشن و تاریک** · ریسپانسیو کامل · RTL · دسترس‌پذیر
- **SEO کامل** — پیش‌رندر، متاتگ‌ها، Open Graph، Schema.org، sitemap، robots و PWA manifest

> ⚠️ داده‌های کاربران در `localStorage` مرورگر ذخیره می‌شود (نسخه بدون بک‌اند).
> یعنی حساب‌ها بین دستگاه‌ها همگام نمی‌شوند و رمزها رمزنگاری‌نشده ذخیره می‌شوند.

### سئو و پیش‌رندر

مهم‌ترین نکته: سایت یک اپلیکیشن React است و اگر محتوا فقط در مرورگر ساخته شود،
موتورهای جستجو یک صفحه خالی می‌بینند. برای همین در زمان بیلد کل صفحه اصلی به
HTML استاتیک تبدیل و داخل `index.html` قرار می‌گیرد (`scripts/prerender.mjs`).

| مورد | قبل | بعد |
| --- | --- | --- |
| متن قابل ایندکس | ۱۶۳ کاراکتر | ~۶٬۰۰۰ کاراکتر |
| تگ `h1` | فقط «FMSMP» | «FMSMP — سرور ماینکرفت فارسی اسلایم‌فان و اقتصادی» |

داده‌های ساختاریافته در `scripts/seo-data.mjs` از روی محتوای واقعی
(`src/data/site.js`) ساخته می‌شوند تا هیچ‌وقت با سایت ناهماهنگ نشوند:
`WebSite`، `Organization`، `VideoGameServer`، `FAQPage`، `HowTo` و `Product`.

یعنی وقتی قیمت رنکی را در `site.js` عوض کنید، قیمت داخل داده ساختاریافته هم
خودکار بروز می‌شود.

### وضعیت زنده سرور

تعداد بازیکنان آنلاین از `api.mcsrvstat.us` خوانده می‌شود و در صورت خطا به
`api.mcstatus.io` سوییچ می‌کند. پاسخ‌ها یک دقیقه در `sessionStorage` کش می‌شوند.
اگر هر دو سرویس در دسترس نباشند، سایت «نامشخص» نشان می‌دهد — نه «آفلاین».

## اجرا در محیط توسعه

```bash
npm install
npm run dev        # http://localhost:5173
```

## ساخت خروجی نهایی

```bash
npm run deploy     # بیلد می‌کند و index.html ریشه را بروزرسانی می‌کند
```

خروجی یک فایل `index.html` **تک‌تکه** است (CSS، JS و تصویر همه inline)، پس روی
GitHub Pages یا هر هاست استاتیک ساده بدون تنظیمات اضافه کار می‌کند.

```bash
npm test           # تست دود: رندر همه صفحات
npm run preview    # پیش‌نمایش خروجی بیلد
```

## پرداخت خودکار (آماده، وصل‌نشده)

پوشه `server/` یک سرویس Node.js دارد که پرداخت را می‌گیرد و **بلافاصله رنک یا
شارد را روی سرور ماینکرفت به بازیکن می‌دهد** — بدون دخالت دستی.

کد نوشته و با ۴۱ تست آزموده شده، اما **هنوز به سایت وصل نیست**: برای فعال‌سازی
به یک VPS، کد پذیرنده زرین‌پال و رمز RCON نیاز است. تا آن زمان سایت خرید را به
دیسکورد ارجاع می‌دهد.

راهنمای کامل راه‌اندازی: [`server/README.md`](server/README.md)

```bash
npm run test:payment   # ۴۱ تست بدون نیاز به سرور واقعی
npm run server         # اجرای سرویس
```

## ویرایش محتوا

بیشتر تغییرات رایج فقط در **یک فایل** انجام می‌شود: `src/data/site.js`

| می‌خواهید چه چیزی را عوض کنید؟ | کجا |
| --- | --- |
| آی‌پی سرور، نسخه، لینک دیسکورد | `SITE` |
| قیمت و امکانات رنک‌ها | `RANKS` |
| بسته‌های شارد | `SHARDS` |
| کارت‌های ویژگی | `FEATURES` |
| مراحل اتصال | `STEPS` |
| قوانین | `RULES` |
| سوالات پرتکرار | `FAQ` |

### تغییر دامنه

اگر دامنه اختصاصی گرفتید، این دو جا را عوض کنید:

1. `src/index.html` — همه `https://fmsmp.github.io/FMSMP/` را جایگزین کنید
   (canonical، og:url، og:image، twitter:image و بلوک JSON-LD)
2. `public/sitemap.xml` و `public/robots.txt`
3. `SITE.url` در `src/data/site.js`

سپس یک فایل `CNAME` با نام دامنه در `public/` بسازید.

## بعد از انتشار: ثبت در گوگل

پیش‌رندر و متاتگ‌ها فقط سایت را **قابل ایندکس** می‌کنند. برای دیده‌شدن در
نتایج جستجو این کارها لازم است:

1. **Google Search Console** — سایت را در <https://search.google.com/search-console>
   ثبت کنید (فایل تأیید `google03bf9272a272cbc1.html` از قبل در ریشه هست) و
   `sitemap.xml` را ثبت کنید، سپس «Request Indexing» بزنید.
2. **لینک از جاهای دیگر** — مهم‌ترین عامل رتبه. لینک سایت را در توضیحات و
   کانال دیسکورد، ویدیوهای یوتیوب، و سایت‌های لیست سرور ماینکرفت بگذارید.
3. **صبر** — ایندکس شدن معمولاً چند روز تا چند هفته طول می‌کشد. رقابت روی
   عبارت «سرور ماینکرفت» زیاد است؛ عبارت‌های دقیق‌تر مثل «سرور ماینکرفت
   اسلایم فان فارسی» خیلی زودتر نتیجه می‌دهند.

پس از ویرایش، `npm run deploy` را اجرا کنید تا `index.html` ریشه بروز شود.
